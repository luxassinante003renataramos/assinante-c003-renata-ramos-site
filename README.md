# Renata Ramos Imóveis PB — GitHub Pages + PWA

Projeto estático, responsivo e instalável diretamente pelo navegador.

## Modos de tela

- Celular vertical: 1080 × 1920
- Tablet vertical: 2048 × 2732
- Tablet horizontal: 2732 × 2048
- Desktop/notebook horizontal: 1920 × 1080

## Alterar os links

Edite apenas `app-config.js`.

## Publicação

Mantenha o mesmo repositório e publique a branch `main` a partir de `/(root)` no GitHub Pages.

## Domínio

O arquivo `CNAME` mantém `www.renataramosimoveispb.com.br`.

## Atualização do PWA

Ao alterar artes, CSS ou JavaScript no futuro, altere em `sw.js`:

`renata-ramos-site-v1` → `renata-ramos-site-v2`
