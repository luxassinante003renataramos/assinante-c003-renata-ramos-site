COMO SUBSTITUIR SEM ALTERAR O LINK DO GITHUB

1. Abra o mesmo repositório já publicado.
2. Não crie outro repositório.
3. Não altere Settings > Pages.
4. Na raiz do repositório, use Add file > Upload files.
5. Envie index.html, style.css e LEIA-ME.txt.
6. O GitHub substituirá os arquivos de mesmo nome.
7. Entre na pasta assets.
8. Apague ou substitua as imagens antigas.
9. Envie:
   capa-celular.png
   capa-tablet.png
   capa-desktop.png
   logo.png
10. Confirme em Commit changes.
11. Aguarde a republicação.
12. Atualize o site com Ctrl + F5.
